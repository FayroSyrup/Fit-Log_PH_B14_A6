# FitLog

A dark, no-nonsense gym companion. Pick a lift, lock it into today's plan, and watch the week's work add up.

Live: https://vercel.com/fayrosyrup/fit-log-ph-b14-a6

## Technologies
- Next.js (App Router)
- Tailwind CSS
- lucide-react (icons)
- react-hot-toast (notifications)

## Features
- Responsive workout library with 12 lifts fetched from an API
- Workout details page with specs and instructions
- Add to today's plan (max 5) and save for later, with live navbar badges
- My Plan page with live metrics, tabs, sort, mark as done and remove
- Data saved in localStorage, plus toasts, loader and a 404 page

## Run locally
npm install
npm run dev
